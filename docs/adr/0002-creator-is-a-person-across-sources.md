# 作者は人であり、源泉ごとの名乗りを台帳が結ぶ

同じ人の本が hitomi・pawchive・pixiv に散り、一箇所で見られなかった。
Eagle の作者根には pawchive の作者も pixiv の作者も既に同居していたので、
作者を「人」と定め、源泉ごとの名前や ID を「名乗り」として BUNKO の台帳が結び、
作者頁が所持と網を横断して並べる。Eagle の作者根は源泉横断の置き場のまま一つにし、
hitomi の本は動かさない (台帳は作者根の中の項目を hitomi の走査から外すので、移すと hitomi の棚から消える)。

## 見送った道

- 源泉ごとに作者根を分ける (`pixiv/<作者>`): 同じ人のフォルダが二つになり、管理が増えるだけ
- 作者フォルダ名に ID を入れて結ぶ: 既存の 44 フォルダは名前に数字が無く、慣わしを変えることになる
