# pixiv の落とし手は BUNKO 自身

pixiv の本を BUNKO で読みたいが、はじめは Powerful Pixiv Downloader (ブラウザ拡張) に落とさせ、
BUNKO は Downloads を見張って取り込むだけの案だった。しかし拡張はブラウザの外で動かせず、
札から落とすには毎回 Edge へ渡る手間が残り、iPhone から頼む道も開かない。
BUNKO には源泉を問わない落とし手 (downloader + `fetchImage`) が既にあるので、
pixiv を nhentai と同じ型の源泉として足し、公式アプリ API を refresh token で叩いて BUNKO 自身が落とす。
本アカウントを使う危うさは PPD と同じ級なので、作法の数字は PPD の既定値にそのまま合わせ
(100 件超で 1.6 秒間隔・画像は同時 6 で 150 件超から 1 秒・429 で 200 秒)、PPD に無い物 (一括は 300 件で休む・裏で回さない・少量で試し撃ち) だけ足す。

## 見送った道

- PPD + 見張りフォルダ: 経路が二本になり、iPhone からの道が無く、Edge への往復が残る
- gallery-dl の子プロセス (kemono-dl と同じ型): 口が変わって追従が面倒になった時の逃げ道として残す
- PPD の移植: 拡張の仕組みはブラウザ前提で、移植は書き直しと同じ。借りるのは知見 (既定値・うごイラの扱い) だけ
